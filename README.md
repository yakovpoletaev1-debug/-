# Бот для ответов марафона

Telegram-бот, который отвечает участникам в группе как живой человек:
- факты берёт из вашей **базы знаний** (`data/knowledge/`);
- манеру ответов перенимает из **истории чата** — как там отвечали организаторы и кураторы;
- видит последние сообщения чата, чтобы понимать контекст;
- отвечает с паузой «печатает…», коротко, без markdown и шаблонных фраз;
- не выдумывает: если ответа в базе нет — говорит, что уточнит.

Ответы пишет Claude (модель `claude-opus-5-5`, при отказе модели включён автоматический
fallback на другую модель).

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. **Важно для групп:** в @BotFather выполните `/setprivacy` → выберите бота → `Disable`.
   Иначе бот в группе не видит обычные сообщения, а значит не понимает контекст.
3. Получите ключ Claude API: https://platform.claude.com/settings/keys
4. Настройте и запустите:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # впишите TELEGRAM_BOT_TOKEN и ANTHROPIC_API_KEY
python -m bot.main
```

5. Добавьте бота в группу и напишите ему: `@имя_бота когда старт?`

Через Docker:

```bash
docker build -t marathon-bot .
docker run --env-file .env marathon-bot
```

## База знаний

Положите в `data/knowledge/` один или несколько файлов `.md` / `.txt`: расписание,
правила, как сдавать задания, частые вопросы. Бот читает их все при запуске
(после изменения — перезапустите бота).

## Обучение на истории чата

1. В Telegram Desktop откройте чат → `⋮` → **Экспорт истории чата**.
2. Снимите галочки с фото/видео, формат — **Машиночитаемый JSON**.
3. Положите `result.json` в `data/chat_export/result.json`.
4. В `.env` в `EXPERT_AUTHORS` перечислите через запятую имена (как в Telegram)
   или `from_id` (например `user123456`) тех, чьи ответы — образец.
   Если оставить пустым, учитываются ответы всех участников.

Бот берёт пары «сообщение → ответ на него (через «Ответить»)» и подражает этому стилю.

## Когда бот отвечает

Сейчас: в личке — всегда, в группе — когда его упомянули (`@имя_бота`) или ответили
на его сообщение. Кроме того, модель сама промолчит, если сообщение не требует ответа.

Свои правила добавляются в `bot/triggers.py` (список `CUSTOM_RULES`), например
«отвечать на все сообщения со знаком вопроса».

## Настройки

Все параметры — в `.env.example` с комментариями: модель, «усилие» модели,
имя/роль бота, сколько примеров и сообщений контекста брать, список разрешённых чатов.
